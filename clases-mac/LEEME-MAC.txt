CLASES EN VIDEO CON AVATAR - GUIA PARA MAC (chip M1/M2/M3/M4)
==============================================================
Cada clase es un video de 2-3 minutos con aspecto de clase por Zoom: la diapositiva con
animaciones, el avatar (SIPANCITOBOT) en el recuadro de camara con tu voz clonada y la
agenda de la clase.

Que hay en esta carpeta
  FICHA-CLASE.txt      la plantilla fija que llenas para cada clase (nombre del avatar, tema...)
  TEXTO-PARA-CLONAR-VOZ.txt  lo que lees para clonar tu voz en ElevenLabs
  CLAUDE.md            el PROMPT MAESTRO: Claude Code lo lee solo, no hace falta pegarlo
  INSTALAR-TODO.command  instala todo en una Mac nueva (una sola vez; ver guias/instalacion/INSTALAR-EN-OTRA-PC.txt)
  CREAR-VIDEO.command  menu para crear los videos (doble clic)
  INSTALAR-VOZ-LOCAL.command  instala la voz local gratis (Piper), una sola vez
  CONECTAR-DRIVE.command  da permiso para subir los videos a Google Drive, una sola vez
  .env.ejemplo         plantilla para tus claves (ElevenLabs, Azure, IA, Google Drive)
  clases/              una carpeta por clase (ya viene html-semantico-w3c de ejemplo)
  salidas/             aqui aparecen los .mp4 terminados
  motor/               el programa que arma el video (no tocar)
  marca/               pon aqui logo.png si quieres el logo oficial


PASO 1 - INSTALAR LO NECESARIO (solo la primera vez, unos 10 minutos)
---------------------------------------------------------------------
1. Abre la Terminal: Cmd + Espacio, escribe Terminal y Enter.
2. Instala Homebrew (el instalador de programas). Pega esto y Enter; te pedira la clave de tu Mac:

   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

3. Al terminar, pega estas 2 lineas (activan Homebrew en tu Mac con chip M):

   echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
   eval "$(/opt/homebrew/bin/brew shellenv)"

4. Instala Node.js y ffmpeg:

   brew install node ffmpeg


PASO 2 - TRAER ESTA CARPETA A TU MAC
------------------------------------
Opcion A (facil): en GitHub abre el repositorio, elige la rama, pulsa Code > Download ZIP,
descomprime el ZIP y mueve la carpeta "clases-mac" a Documentos.
Opcion B (git):   cd ~/Documents && git clone <url-del-repositorio>

En los pasos siguientes se asume que la carpeta quedo en:  ~/Documents/clases-mac
(si usaste git, sera ~/Documents/cursos-videos-ia/clases-mac)


PASO 3 - PRIMERA PRUEBA GRATIS (sin cuentas, sin internet)
----------------------------------------------------------
En la Terminal:

   cd ~/Documents/clases-mac
   npm install
   npx playwright install chromium
   node motor/crear-video.mjs html-semantico-w3c --vista

Se abre el navegador: pulsa "Reproducir clase con sonido". Es la clase de ejemplo con la voz de
macOS y el robot SIPANCITOBOT. Para crear el MP4 final:

   node motor/crear-video.mjs html-semantico-w3c

El video queda en salidas/html-semantico-w3c.mp4 (en una M4 tarda unos minutos).
Tambien puedes hacer todo con doble clic en CREAR-VIDEO.command.
La primera vez macOS lo bloquea: clic derecho > Abrir > Abrir. Si no te deja, usa la Terminal:
   bash CREAR-VIDEO.command

Esta prueba usa la voz de macOS, que suena sintetica. En el PASO 4 la cambias por TU voz.
Si sale en ingles o no hay voz en espanol: Ajustes del Sistema > Accesibilidad >
Contenido leido > Voz del sistema > Gestionar voces > Espanol (descarga Paulina o Monica Premium).


PASO 4 - UNA VOZ NATURAL (elige una opcion)
--------------------------------------------
La voz de macOS de la prueba es sintetica: sirve para probar, no para publicar.
Tienes tres opciones, de la mas simple a la mas comoda.

4A) TU VOZ GRABADA (gratis, la mas natural; recomendada para empezar)
    OJO: esto NO clona tu voz. Tu grabacion ES la narracion del video, por eso tienes que
    leer el guion de ESA clase completo. (Clonar = 4B.)
    1. Abre CREAR-VIDEO.command, elige la clase y la opcion 5 (Guion para grabar TU voz).
       Se abren el guion y la carpeta voz de la clase.
    2. Graba el guion de corrido con QuickTime Player (Archivo > Nueva grabacion de audio) o con
       Notas de voz, y CALLA 2 SEGUNDOS ENTRE BLOQUE Y BLOQUE.
    3. Guarda la grabacion como  clases/<clase>/voz/completa.m4a
    4. Crea el video (opcion 1). El programa corta tu grabacion en bloques solo, le quita el
       ruido de fondo y sincroniza cada diapositiva con tu voz. SIPANCITOBOT habla con tu voz.
    Si un bloque te sale mal, graba solo ese bloque como voz/05.m4a (por ejemplo) y listo.

4B) TU VOZ CLONADA CON ELEVENLABS (unos US$6 al mes; ya no tienes que grabar cada clase)
    1. Graba 1 o 2 minutos leyendo TEXTO-PARA-CLONAR-VOZ.txt (ahi estan los consejos).
       Un audio de WhatsApp de 5 segundos NO alcanza: hace falta 1-2 minutos de buena calidad.
    2. Crea tu cuenta en https://elevenlabs.io y elige el plan Starter (incluye Instant Voice Cloning).
    3. Ve a Voices > Create / Add a new voice > Instant Voice Clone. Sube tu grabacion, confirma que
       es TU voz y guardala con un nombre (ej.: "Mi voz clases").
    4. En tu voz pulsa el menu (...) > Copy voice ID.
    5. Crea tu API key en Developers (o Settings) > API Keys > Create API key, con permiso
       Text to Speech, y copiala.
    6. En la Terminal, dentro de la carpeta:

       cp .env.ejemplo .env
       open -e .env

       Pega la API key en ELEVENLABS_API_KEY= y el Voice ID en ELEVENLABS_VOICE_ID=, y guarda.
       (.env es un archivo oculto: en Finder se ve con Cmd + Shift + punto.)
    7. Crea el video de nuevo. Ahora toda clase nueva sale con tu voz clonada, sin grabar nada.
       Si vuelves a renderizar sin cambiar el texto, NO se gastan creditos.
       Una clase de 2:30 son unos 2.200 caracteres; el plan Starter (30.000 creditos al mes)
       alcanza para unas 10-13 clases nuevas al mes.
    Nota: si existe voz/completa.m4a o camara.mp4, se usa eso antes que ElevenLabs.

4C) MEJOR VOZ DE macOS (gratis, sigue siendo sintetica)
    Ajustes del Sistema > Accesibilidad > Contenido leido > Voz del sistema > Gestionar voces >
    Espanol: descarga "Paulina (Premium)" o "Monica (Premium)". El programa usa sola la mejor que
    encuentre y evita las voces roboticas (Eddy, Flo, Rocko...).

4D) VOZ LOCAL GRATIS CON PIPER (sin internet, sin cuenta, sin limite de videos)
    1. Doble clic en INSTALAR-VOZ-LOCAL.command (necesita Python 3: brew install python).
       Descarga unos 150 MB, solo la primera vez. Al final suena una prueba.
    2. En .env pon  VOZ=local  (o en la web: Voz y avatar > Voz local gratis).
    Otra voz: bash INSTALAR-VOZ-LOCAL.command es_AR-daniela-high  y en .env  PIPER_VOZ=es_AR-daniela-high

4E) AZURE (voces neurales con acento de Peru; 0,5 millones de caracteres gratis al mes)
    Una clase usa unos 2 000 caracteres: el plan gratis alcanza para unas 240 clases al mes.
    1. https://portal.azure.com > Crear un recurso > "Speech" > plan Free F0 > anota la region.
    2. En el recurso: Keys and Endpoint > copia KEY 1.
    3. En .env:  AZURE_SPEECH_KEY=<la clave>  y  AZURE_SPEECH_REGION=eastus  (y VOZ=azure si
       quieres usarla siempre). Voces: es-PE-CamilaNeural (por defecto) o es-PE-AlexNeural.

NO uses varias cuentas gratis (correos temporales) para juntar caracteres: va contra las
condiciones de ElevenLabs y Azure, pueden bloquear todas las cuentas (tambien la de tu voz
clonada) y el plan gratis de ElevenLabs no permite uso comercial ni voces clonadas.

IMPORTANTE: clona solo TU voz, o la de alguien que te de su permiso por escrito.
Nunca subas .env, tus grabaciones (voz/) ni tus videos (camara.mp4) a GitHub: ya estan
excluidos en .gitignore.


PASO 5 - CREAR CLASES NUEVAS CON CLAUDE CODE
--------------------------------------------
1. Instala Claude Code (en la Terminal):

   curl -fsSL https://claude.ai/install.sh | bash

   Cierra y abre la Terminal y comprueba con:  claude --version
2. Claude Code necesita un plan de pago de Claude: Pro (unos US$20 al mes) o superior, o una
   cuenta de Console con API key (pago por uso). El plan gratis de claude.ai NO incluye Claude Code.
   Con el plan Pro no necesitas API key: solo inicias sesion la primera vez.
3. Llena FICHA-CLASE.txt con tu tema y guardalo.
4. En la Terminal:

   cd ~/Documents/clases-mac
   claude

   y escribe:  crea la clase de la ficha
5. Claude Code te hara las preguntas que falten y te mostrara el guion. Responde "ok" y creara
   la clase, revisara las capturas y generara el video en salidas/.


PASO 6 (OPCIONAL) - TU CARA O UN AVATAR REALISTA EN VEZ DEL ROBOT
------------------------------------------------------------------
El robot incluido es gratis y mueve la boca con tu voz. Otras opciones:

TU EN CAMARA (gratis, clase Zoom real): grabate con Photo Booth o QuickTime (Archivo > Nueva
grabacion de video) leyendo el guion de la opcion 5, con 2 segundos de pausa entre bloques.
Guarda el video como clases/<clase>/camara.mp4. Tu video va al recuadro de camara, tu voz es la
del video y las diapositivas cambian solas en cada pausa. Pon tu nombre en "docente" de clase.json.

AVATAR REALISTA (HeyGen / Hedra, de pago):
1. Genera solo la voz (opcion 4 del menu, o):  node motor/crear-video.mjs <clase> --solo-voz
2. En HeyGen (Avatar IV / foto avatar) o en Hedra, sube una imagen de tu avatar y el audio
   clases/<clase>/salida/voz-completa.mp3. Descarga el video.
3. Guardalo como clases/<clase>/avatar.mp4 y vuelve a crear el video: aparecera en el recuadro
   de camara en lugar del robot.
Nota: LiveAvatar de HeyGen es para avatares EN VIVO (no guarda MP4); para clases grabadas usa
el HeyGen normal o Hedra.


PASO 7 (OPCIONAL) - TUS PROPIAS LAMINAS (IMAGENES O PDF)
---------------------------------------------------------
Si ya tienes tus diapositivas (Keynote, PowerPoint, Canva), en la web: Nueva clase >
"Mis laminas (imagenes)" y sube un PDF o las imagenes PNG/JPG (Keynote: Archivo > Exportar a > PDF).
Cada lamina es un bloque del video. La voz la escribes tu (un parrafo por lamina), la IA gratis
(un modelo que lee imagenes: qwen/qwen3.8-27b en Groq o gemini-3.8-flash en Gemini; web: Ajustes >
IA que lee laminas) o Claude (de pago por uso). Grok (xAI, de pago) tambien lee imagenes.


PASO 8 (OPCIONAL) - GOOGLE DRIVE: LOS VIDEOS EN LA CARPETA COMPARTIDA DEL EQUIPO
--------------------------------------------------------------------------------
Cada video final se sube solo, con la clase en HTML (salidas/<clase>.html: se abre con doble clic en
cualquier navegador y se ve la clase con su voz) y su codigo (clase.json, diapositivas, laminas), a:
   <carpeta compartida> / Videos de clases IA / 2026-10 / <Curso> / Video con HTML / <Modulo> / <clase>
                                                              / Video con laminas / <Modulo> / <clase>
   (una carpeta por tipo de lamina: HTML animadas o las laminas del docente)
Todos los que tienen acceso a la carpeta lo ven. Tu cuenta debe ser Editor de esa carpeta.

OPCION A - API DE GOOGLE
  1. https://console.cloud.google.com con tu cuenta @uss.edu.pe > proyecto nuevo.
  2. APIs y servicios > Biblioteca > "Google Drive API" > Habilitar.
  3. Pantalla de consentimiento de OAuth > tipo de usuario INTERNO.
  4. Credenciales > ID de cliente de OAuth > tipo APP DE ESCRITORIO > Descargar JSON.
  5. Guardalo en esta carpeta como  google-drive-cliente.json  (o pegalo en la web: Ajustes > Google Drive).
  6. Doble clic en CONECTAR-DRIVE.command y acepta el permiso con la cuenta que es Editor de la carpeta.
  7. En .env (o en la web) pega el enlace de la carpeta:  DRIVE_CARPETA_ID=https://drive.google.com/drive/folders/...

OPCION B - GOOGLE DRIVE PARA ESCRITORIO (sin Google Cloud)
  1. Instala Google Drive para escritorio (brew install --cask google-drive) e inicia sesion.
  2. En drive.google.com: clic derecho en la carpeta compartida > Organizar > Agregar acceso directo > Mi unidad.
  3. En .env:  DRIVE_RUTA_LOCAL=/Users/<tu-usuario>/Library/CloudStorage/GoogleDrive-<tu-correo>/Mi unidad/<carpeta>

Para subir una clase a mano:  node motor/drive.mjs subir <clase>   (con --prueba solo muestra que subiria)

PROBLEMAS FRECUENTES
--------------------
- "command not found: brew": repite el punto 3 del PASO 1.
- "No encuentro ffmpeg": brew install ffmpeg
- "Executable doesn't exist ... chromium": npx playwright install chromium
- ElevenLabs "HTTP 401": la API key esta mal copiada o no tiene permiso de Text to Speech.
- ElevenLabs "HTTP 404": el Voice ID no es de tu cuenta.
- Azure "HTTP 401": la clave esta mal copiada o AZURE_SPEECH_REGION no es la region de tu recurso.
- "falta la voz es_MX-claude-high": abre INSTALAR-VOZ-LOCAL.command.
- Drive "404 / no veo la carpeta": revisa DRIVE_CARPETA_ID y que tu cuenta sea Editor de esa carpeta.
- Drive "el permiso vencio": abre CONECTAR-DRIVE.command otra vez.
- "sin creditos": se acabo el mes del plan; mientras tanto se usa la voz de macOS.
- Algo fallo: copia el mensaje de la Terminal y pegaselo a Claude Code.
