F12Crear una clase con Claude Code (terminal)

Producir una clase a pedido del equipo desde la terminal, con Claude Code siguiendo el prompt maestro (CLAUDE.md): ficha, guion aprobado, diapositivas, revisión con capturas y video.

CódigoF12

DisparadorLlega una ficha (FICHA-CLASE.txt) o un pedido
RequisitosClaude Code abierto en la carpeta clases-mac o clases-windows
EntradasFicha de la clase
Salidasclases/<nombre>/ con clase.json, video MP4, HTML y GUION-PARA-GRABAR.txt
SistemasClaude Code · motor de video

Diagrama del flujo

Cada carril es un actor y los pasos van de arriba abajo. Las cajas punteadas son decisiones: «Sí» sigue la flecha; la otra salida está en la tabla de pasos (◆).

Pasos del flujo

N.°ActorPasoQué pasa
1 Docente o equipoLlena FICHA-CLASE.txtTema, nivel, duración, objetivo, puntos, ejemplo y reto.
2 ◆ Claude Code¿Falta algo en la ficha?Pregunta todo en un solo mensaje, numerado y con opciones.
3 Claude CodeMuestra el guion en una tablaBloque · segundos · lo que dice la voz · qué se ve; con el total de palabras.
4 Docente o equipoDa el «ok»
5 Claude CodeCrea clases/<nombre>/clase.json (con diapositivas por plantillas) y ficha.txt.
6 Motor de videoHace capturas (--capturas)Claude Code revisa todas las fotos y corrige hasta que estén limpias.
7 Motor de videoRender final y HTMLnode motor/crear-video.mjs <nombre>
8 Claude CodeReporta duración, voz y ruta del MP4Y genera GUION-PARA-GRABAR.txt para el docente.

Reglas del negocio

  • Claude Code nunca lee ni muestra .env, google-drive-cliente.json ni drive-token.json.
  • No modifica motor/ para una clase concreta: un error del motor se explica y se propone.
  • No inventa datos, citas ni estadísticas.
